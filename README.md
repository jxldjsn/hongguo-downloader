### 二、 👥 账号批量下载与主页抓取中心

1. **创作者全量作品抓取 (抖音 / 快手 / B站 / TikTok)**：
   - 输入作者主页链接或 `sec_user_id`，一键递归抓取所有已发布作品；
   - 支持按发布时间倒序排列、实时识别已下载/未下载状态，支持增量补全。
2. **小红书博主全量笔记抓取**：
   - 批量解析博主名下全部图文与视频笔记，自动建立作者专属文件夹归档。
3. **“我的账号”资产一键备份**：
   - 支持已登录账号的**个人已发布作品、喜欢（点赞）列表、收藏夹列表**一键批量导出备份。
4. **直播流实时录制**：
   - 输入正在开播的抖音、快手、TikTok 直播间分享链接，自动抓取最高码率的 FLV / HLS 实时拉流源，无损录制为本地视频。
5. **作品评论深度抓取**：
   - 一键抓取目标视频下的全部评论（包含评论人昵称、头像、评论文本、点赞数、发布时间、IP 属地、二级回复等）；
   - 一键导出标准 CSV / Excel 报表，用于舆情监控、精准引流拓客、爆款文案提炼与用户情绪画像。
6. **抖音官方实时热榜**：
   - 实时抓取抖音热搜榜、上升榜、挑战榜、热门视频榜，掌握第一手流量趋势；
   - 支持热榜数据全量导出 CSV，辅助选题策划与热点借势。

### 三、 📊 矩阵运营中心与分组爆款分析（核心特色）

1. **多账号资产矩阵管理**：
   - 支持按赛道（美妆、数码、影视剪辑、带货、知识等）自定义创建账号分组；
   - 账号链接/ID 支持按行批量粘贴导入，统一归类管理对标达人与竞品库。
2. **🔥 分组爆款分析引擎 (Hot Video Analysis)**：
   - **时间维度筛选**：支持最近 7 天、15 天、30 天或自定义时间跨度；
   - **数据指标筛选**：点赞数区间、播放量区间、评论量、分享量、点赞增长阈值；
   - **自研多维算法排序**：
     - **爆款指数 (Hot Index)**：综合互动率与发布时长的爆款评估模型；
     - **点赞密度 (Like Density)**：单位时间内的点赞爆发力；
     - 点赞总量、播放总量、发布时间等多维度重排序；
   - **快照基准分析**：即使离线未保持后台开启，也能基于作品快照数据快速算出阶段性表现最佳的潜力爆款。
3. **爆款数据一键输出与利用**：
   - **一键复制链接**：一键批量提取筛选出的所有爆款视频链接（一行一条），直接贴入剪辑软件或素材库；
   - **CSV / Excel 报表导出**：导出包含作品封面、标题、各项互动指标、作者信息、直达链接的完整数据报表。

### 五、 🧰 创作者效率工具箱

1. **智能文本提取工具 (Text Tool)**：
   - 从微信群聊、社群、文案等混杂长文本中，一键秒级提取所有视频/图集有效链接；
   - 自动清洗多余中文描述、系统口令字符，支持去重与格式化输出。
2. **内置安全微浏览器 (Quick Browser)**：
   - 内置沙盒级极速浏览器，方便在软件内直接打开目标网页并触发流媒体深度嗅探。
3. **多平台 Cookie 授权管理器**：
   - 内置隔离登录窗口，支持账号扫码登录；
   - 平台登录凭据全部采用 Windows 原生加密技术安全存储在本地，不上传任何云端，保障账号绝对隐私；
   - 支持随时一键清除平台会话、缓存与 Cookie，干干净净。

### 六、 ⚡ 稳健底座与下载管理引擎

- **十万级数据持久化**：采用嵌入式 SQLite 本地数据库，长期管理成千上万条作品与账号数据依然流畅。
- **智能下载队列**：支持多任务并行调度、自定义并发线程数、随时暂停/恢复/终止。
- **文件防损校验**：下载时统一先写入临时 `.part` 分片文件，校验完整无误后再命名合并为最终媒体文件，杜绝损坏文件入库。
- **单实例进程守护**：防止多开导致的文件写入冲突与资源占用，重复启动自动呼出当前主窗口。
- **代理支持**：支持配置 HTTP / Socks5 代理，轻松兼容 YouTube 与海外平台下载。

## 🛠️ 开发者：本地运行与源码构建

### 环境准备
- 操作系统：Windows 10 / 11 x64
- Node.js：>= 22.12.0 (x64)
- npm：>= 10.0.0

### 本地启动

```powershell
# 1. 克隆代码仓库
git clone https://github.com/327044572/douyin-downloader.git
cd douyin-downloader

# 2. 安装 NPM 依赖
npm install

# 3. 启动开发模式（同时拉起 Vite 前端与 Electron 桌面端）
npm run dev
```

### 离线检查与生产打包

```powershell
# 离线语法与组件测试检查
npm run check

# 打包生成 Windows x64 NSIS 安装程序（输出到 release/ 目录）
npm run build:win
```
