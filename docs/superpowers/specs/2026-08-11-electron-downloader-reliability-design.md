# Electron 下载器可靠性与安全修复设计

## 目标

在保持现有 React 页面、`window.electronAPI` 方法名和主要用户流程兼容的前提下，修复 Windows x64 Electron 客户端的下载队列、取消/删除、重试恢复、文件完整性、前端批量操作、Cookie 管理、导航与 IPC 安全、数据库落盘以及打包依赖问题。

## 范围

本设计只覆盖项目根目录下的 Electron、React 和 Node.js 代码，最终发布平台仅为 Windows x64。

明确排除以下目录及其全部内容：

- `抖音下载器源码/`

该 Python 子项目不修改、不移动、不删除、不测试，也不重新接入 Electron。

## 兼容性约束

- 保持现有页面入口和主要交互结构不变。
- 保持 preload 已公开的方法名及现有 IPC channel 名称不变；允许在返回对象中增加字段。
- 已保存的旧下载记录必须能完成数据库迁移；不能恢复执行参数的旧任务应显示明确错误，并允许从稳定作品链接重新解析。
- 下载目录、命名模板和已有账号数据不得被无提示清空。
- 不支持 Windows ia32、macOS 或 Linux 安装包。

## 方案选择

采用兼容式分层修复，而不是继续在 `main.js` 中追加互相独立的补丁，也不重写整个应用。

新增小型、可测试的核心模块，现有 IPC handler 逐步改为调用这些模块。下载站点解析器保持现状，只有涉及任务生命周期、文件输出和安全边界的部分进入本次重构。

## 架构

### 1. 下载任务状态机

任务状态统一为：

- `parsing`
- `pending`
- `running`（对 renderer 仍序列化为兼容的 `downloading`）
- `completed`
- `partial`
- `failed`
- `stopped`
- `deleted`

终态为 `completed`、`partial`、`failed`、`stopped`、`deleted`。任务只能通过状态机转换状态，终态不能被较晚到达的流事件覆盖。

每个运行任务拥有统一的运行时上下文：

- `AbortController`
- 当前可写流
- 当前 HTTP 响应流
- 当前子进程及其进程树终止函数
- 唯一的 `finalize()`

`finalize()` 负责清理运行时资源、持久化最终状态和发送一次最终事件。停止、删除、网络错误和成功完成都必须经过它。

### 2. 并发调度器

队列调度器使用非阻塞的 `pump()` 循环，在存在空闲槽位时持续启动任务，直到达到配置的并发上限。任务完成或停止后释放槽位并再次调度。

停止等待中的任务时必须将其从队列移除。调度器启动任务前再次确认任务仍是 `pending`，防止已停止或删除的任务被执行。

任务 ID 去重由调度器负责；同一任务不能同时运行两次。重试只允许 `failed`、`partial` 或 `stopped` 状态。

### 3. 任务持久化

数据库为下载任务增加以下字段：

- `payload_json`：保存各任务类型的完整执行参数。
- `payload_version`：用于后续迁移。
- `revision`：解决初始快照与实时事件的覆盖问题。
- `updated_time`：用于排序和合并。

`payload_json` 仅保存可序列化的执行参数，不保存流、取消器或子进程。不同任务类型在入队和重试前使用对应 schema 校验。

进度更新采用单任务 UPSERT，不再删除整张表。数据库导出仍使用临时文件加原子替换，但落盘失败必须向调用方传播并保留 dirty 状态。

### 4. 文件输出和完整性

所有下载先写入任务唯一的同目录临时文件，例如：

`.<最终文件名>.<任务ID>.part`

只有满足成功条件后才原子改名为最终文件：

- HTTP 流正常结束，未触发 `aborted` 或 `error`。
- 存在 Content-Length 时，接收长度与声明长度一致。
- 合并任务的 ffmpeg 退出码为 0。
- 最终文件存在且大小大于 0；媒体文件执行轻量容器探测。

文件名统一清理 Windows 非法字符、保留设备名和尾随空格/点。最终路径必须位于经授权的下载根目录或用户通过文件夹选择器授予的目录内。同名文件按作品 ID或递增序号避让，不允许并发覆盖。

图集记录每一项的成功/失败结果。存在失败项时状态为 `partial`，进度不能把失败项计为成功，并支持只重试失败项。

### 5. HLS、DASH 和外部下载工具

HLS/MPD 不再依靠不完整的字符串或正则解析器下载分片。主流程把原始 manifest URL、Referer、User-Agent 和必要请求头交给 ffmpeg；平台必须使用白名单协议。

yt-dlp 和 ffmpeg 的进程句柄进入任务运行时上下文。停止时终止 Windows 进程树。进程退出 0 后仍需确认目标文件存在并通过完整性检查。

B站 Cookie 不再通过命令行 `--add-header` 传递，改用权限受限的临时 Netscape Cookie 文件，并在正常结束、失败、停止以及下次启动清理过期文件。

### 6. Electron 安全边界

- 主窗口仅允许生产环境的本地 `file:` 页面或开发环境的固定 localhost origin。
- 其他 HTTP(S) 导航一律阻止并交给系统浏览器；自定义协议一律拒绝。
- `shell.openExternal` 仅允许 `https:`，需要 HTTP 的明确站点使用精确域名白名单。
- 每个高权限 IPC handler 校验 sender URL，并对参数做长度、类型、URL、路径和枚举验证。
- `webview` 创建时通过 `will-attach-webview` 移除未知 preload、关闭 Node integration、启用 sandbox，并限制站点和权限。
- 控制端恢复证书校验和正确 SNI；更新与推广 URL使用 HTTPS 白名单。

### 7. Cookie 和凭据

Cookie 的数据真相源保留在主进程，敏感值使用 Electron `safeStorage` 加密后落盘。renderer 只接收登录状态、Cookie 数量和脱敏元数据，不接收完整 Cookie。

清除登录态必须同时完成：

- 清理 Electron partition。
- 删除 SQLite 和 electron-store 中的平台 Cookie。
- 销毁或重建对应平台 API/隐藏窗口。
- 删除相关临时 Cookie 文件。

日志中不得出现 Cookie、Authorization 或带凭据的完整命令行。

### 8. React 下载交互

- 快速下载按原始解析数组索引生成默认选中集合。
- 所有批量入队使用 `Promise.allSettled()` 或单个批量 IPC，统计真实成功与失败数量后再跳转。
- 所有运行任务都显示“停止”，不再把停止误称为暂停。
- 批次聚合状态区分 `completed`、`partial`、`failed` 和 `stopped`；只要存在失败就不能显示纯完成。
- 下载快照和实时事件按 `id + revision` 合并，防止旧快照覆盖新事件或产生重复项。
- 组件保存 preload 注册函数返回的 unsubscribe，并只移除自己的监听器。
- 通用嗅探使用 URL 到资源的 Map；后续更具体的媒体类型可以替换早期分片类型。
- 单项下载和“下载全部”共用同一资源类型分派函数。

### 9. 设置和数据库体验

保留并实际接入的设置：下载根目录、文件夹模式、命名模板、并发数、请求超时、重试次数和代理。

当前没有实现语义的最大文件大小、分块大小、音乐、动态封面和静态封面选项从界面移除，避免保存成功但不生效。设置保存前验证有限数值和范围；主进程返回失败时 UI 不得显示成功。

### 10. Windows x64 打包和依赖

- electron-builder 仅生成 Windows x64 NSIS 安装包。
- 输出目录改成项目内相对路径。
- 删除无效 macOS 配置和 ia32 target。
- 构建时验证 yt-dlp、ffmpeg 和 Electron 架构为 x64。
- 升级有安全修复的 axios、Electron、electron-builder、Vite 等依赖，并逐级验证兼容性。
- `xlsx` 替换为维护中的安全实现或限制在经过净化的纯导出适配层。
- `sm-crypto` 升级后验证当前 SM3 输出兼容。

## 错误处理

所有 IPC 返回统一结构：

```js
{ success: true, ...data }
{ success: false, code, error }
```

现有调用保持兼容。新增稳定错误码用于区分参数错误、路径越界、网络取消、完整性失败、工具缺失、持久化失败和不支持的任务恢复。

用户主动停止不记录为失败；部分文件成功使用 `partial`；无法恢复的旧任务显示“需要重新解析原链接”。

## 测试策略

新增基于 Node 内置测试运行器的第一方测试，避免先引入大型测试框架。

必须覆盖：

- 调度器会填满并发槽位且不超限。
- pending 任务停止后绝不执行。
- stopped/deleted 终态不会被 finish/error 覆盖。
- 每种任务 payload 数据库往返一致。
- 旧任务迁移和不可恢复错误提示。
- 本地假 HTTP 服务的正常流、取消、截断、错误 Content-Length 和上游 error。
- `.part` 成功原子发布和失败清理。
- 图集部分成功状态和失败项重试。
- HLS/MPD/yt-dlp 子进程取消、非零退出和无输出文件。
- 文件名、路径边界、外部 URL 和 IPC sender 校验。
- Cookie 清除后重启不恢复，日志不包含敏感值。
- 快速下载选中索引、批量部分失败、批次聚合和资源类型升级。

现有离线 Electron 测试、JS/JSX 语法解析、生产 Vite 构建和 npm 依赖审计继续作为交付门禁。不会在自动测试中访问真实账号或真实平台。
